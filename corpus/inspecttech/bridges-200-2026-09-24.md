# bridges-200-2026-09-24: bridge evaluation report

Evaluated **200 new WVDOT-owned, in-service bridges**; the original three pilots are excluded.

| Result | Bridges |
| --- | ---: |
| All three preliminary flood surfaces generated | 40 |
| Terrain prepared; complete flood results unavailable | 85 |
| Inputs rejected before scene preparation | 75 |

This produced **120 flood scenarios**. Missing flood results mean unresolved modeling/data, not absence of flooding.

## Gaps and required follow-up

| Gap | Sites | Required follow-up |
| --- | ---: | --- |
| Mixed-flow model required | 41 | Build a mixed-flow/2D study with surveyed channel and bridge geometry; the subcritical pilot solver cannot resolve this site. |
| Stream geometry incomplete or misaligned | 36 | Correct stream connectivity/snapping using authoritative linework or a site-specific study. |
| Regional hydrology not covered | 33 | Add and validate the applicable regional equations; use region-weighted hydrology where needed. |
| Wider floodplain sections required | 30 | Extend the terrain and cross sections to contain the flood, then rerun the hydraulic calculation. |
| Basin outside regression limits | 6 | Obtain a site-specific flood-frequency estimate or applicable gage/study discharges. |
| Downstream boundary/slope unresolved | 6 | Establish a longer reach or surveyed/calibrated downstream boundary condition. |
| Local DEM coverage incomplete | 4 | Expand the lidar patch to cover all required cross sections. |
| Hydraulic profiles require investigation | 4 | Inspect terrain, flow path and boundary conditions before accepting a scenario. |

## Terrain reuse and timing

- Shared one lossless Terrain-RGB archive: 2.52 GiB, 33,131 tiles. The supplied file remains unchanged.
- Downloaded 120 distinct local lidar patches during this batch workflow. Nearby bridges share patches; surrounding terrain requires no elevation API calls.
- Map tiles are generated only when viewed and cached. Calculations use the local lidar, not archive elevations.
- Median evaluated-site worker time: 14.9 seconds. Median completed-scene worker time: 19.4 seconds.
- Timings are per-worker durations including source requests, not batch wall time. Resumed cached attempts can be faster. Lidar retries are not included in the patch count.

## Scope and interpretation

New in-service WVDOT-owned named water crossings, BMP/EMP length 15–150m, width 3–30m; county round-robin; original pilots excluded.
This is a deterministic convenience sample, not a random statewide sample or a bridge-risk ranking. Rejected cases remain in the denominator. All accepted flood scenes are preliminary; bathymetry, roughness, datum and bridge pressure-flow assumptions remain as documented in the viewer.

## Verification

All 200 API scene states matched the report. All 120 generated flood scenarios passed WSE/depth/terrain consistency checks, and 1,375 immutable scene assets passed checksum verification. Nearby archive coverage checks inspected 213 tiles without a missing or implausible elevation tile. The backend suite passed 79 tests; the browser suite passed 7 tests.
